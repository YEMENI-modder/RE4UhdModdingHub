# Separate Items From Stack

**الوصف:** يفصل الأصناف في التكديس — كل نوع مع نوعه فقط

**Description:** Separates item stacking so only similar items stack together

**ملاحظات:**
- [!] الرمانات وسهام القوس تشترك في نفس قيمة الـ stack

**Notes:**
- [!] Grenades and bowgun darts share the same stack value
