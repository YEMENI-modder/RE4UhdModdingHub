# Random Ptas Quantity

**الوصف:** تحدد كمية العملات العشوائية اللي تطيح

**Description:** Set the amount of randomly dropped Ptas

أول شي تفعل ذا الكود:

```
Find : 1B87FC
Paste : BE 0A 00 00 00 E9 91 00 00 00 90 90 90 90 90 90
```

ومن بعدها ابدأ عدل قيمة `1B87FD` وذي التفاصيل:

- Byte Count: 1
- Divide By: 10
- Default: 100
