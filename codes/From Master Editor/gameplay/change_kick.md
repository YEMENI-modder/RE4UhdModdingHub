# تغيير الكيك
*Change Kick*

**الوصف:** يغير الكيك الخاص بليون

**Description:** Changes Leon's kick animation

**قيمة اختيارية (dropdown) — Offset:** 566A2

**Options:**

- Kick Leon (Default) (كيك ليون (افتراضي)) -> `74 3F`
- Kick Hunk (كيك هانك) -> `EB 3F`
- Kick Krauser (كيك كراوسر) -> `EB 2C`
- Kick Wesker (كيك ويسكر) -> `EB 19`
