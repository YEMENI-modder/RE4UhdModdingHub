# Punisher Piercing Shot Count

**الوصف:** تحدد كم عدو يمدي الـ Punisher يخترق

**Description:** Set how many enemies the Punisher can pierce through

- Pierce Count (Normal) — عدد الاختراق (عادي)
  Offset: 285E17 | Byte Count: 4 | Prefix: B8 | Default: 2

- Pierce Count (With Exclusive) — عدد الاختراق (مع التطوير الأخير)
  Offset: 285E1E | Byte Count: 4 | Prefix: B8 | Default: 5
