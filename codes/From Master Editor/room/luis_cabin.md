# Luis Cabin Time & Enemy Count

**الوصف:** تعديل وقت وعدد أعداء كبينة لويس

**Description:** Customize time limit and enemy kill count for Luis cabin

- Time Limit (Normal) — Offset: 0x4B44C5 | 2 bytes | Default: 60
- Time Limit (Easy) — Offset: 0x4B44D5 | 2 bytes | Default: 90
- Kill Count (Normal) — Offset: 0x4B44CC | 1 byte | Default: 10
- Kill Count (Easy) — Offset: 0x4B44DC | 1 byte
